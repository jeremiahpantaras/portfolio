# Jeremiah Pantaras - Portfolio Website

A modern, responsive portfolio website showcasing my professional journey as a Junior Software Engineer and Full-Stack Developer.

A dark, minimalist single-page app: a typographic hero over a realistic procedural night sky (Milky Way and northern lights, no photos or video) that flows as you scroll, project, capabilities and experience sections, a creative side (`/creative`), and an AI assistant chat.

## Stack

React 19 · Vite 7 · React Router 7 · Tailwind CSS 4 · GSAP (+ ScrollTrigger, SplitText) · Vercel (hosting, Analytics, Speed Insights) · Gemini (chat).

## Getting started

```bash
npm install
npm run dev        # local dev server (http://localhost:5173)
npm run build      # production build -> dist/
npm run preview    # serve the production build locally
npm run lint       # ESLint
```

There are no automated tests and no type-check step (the two `.ts`/`.tsx` files are only transpiled by Vite).

## Editing content

All portfolio content lives in `src/data/` (one source for the home page and the sub-pages):

| File | Content |
| --- | --- |
| `profile.js` | name, title, hero pitch, bio, company, CV paths, portrait |
| `projects.js` | every project (`links.live` / `links.source` only when a real URL exists) and the featured six |
| `experience.js`, `recognition.js`, `techStack.js`, `socials.js`, `nav.js` | the matching sections |
| `portfolio-context.json` | the facts the AI chat answers from (keep in sync with the files above) |

Routes are declared in `src/App.jsx`; every route except `/` is code-split.

## Images

Large originals stay in `public/` untouched. The site uses optimised WebP derivatives in `public/images/`, generated by:

```bash
node scripts/optimize-images.mjs [--force]
```

It needs the `cwebp` binary (macOS: `brew install webp`) and also rewrites `src/data/imageMeta.json`, which supplies `width`/`height` to prevent layout shift. After adding a photo, add it to the relevant list in `scripts/optimize-images.mjs` and run the script.

## Design and motion

- Design tokens (colours, fonts, type scale) are in `src/index.css`; `tailwind.config.js` is not used by Tailwind 4.
- GSAP plugins are registered once in `src/lib/gsap.js`. Scroll reveals are declarative (`data-reveal="…"` attributes + `src/hooks/usePageReveal.js`).
- The Creative page's `ChromaGrid` (`src/creatives/components/ui/`) is a vendored React Bits component (MIT + Commons Clause).
- The home page's background is one fixed WebGL canvas (`src/components/motion/AuroraScene.jsx` + `AuroraCanvas.jsx`), painted by one fragment shader with no photos or video: a procedural Milky Way (bright core, dust lane, star clouds), stars with stellar colours, a volumetric-style aurora (curtains made of layers sampled along the view ray, with rays, green at the bottom to violet at the top and a pink lower edge), a snow-capped mountain range (a tall peak with rock faces and snow patches, lit from the left, with lower ranges on each side) that pops up behind the Contact section when you reach the end of the page. Scrolling moves the sky from the inside, as if you were falling through it: the curtains drift toward you and zoom, the Milky Way and stars slide up, the camera tilts up a little; past the hero the aurora dims to a faint glow (`FLOOR`, `HERO_FADE` in `AuroraCanvas.jsx`), the mountains pop up when the footer comes into view, and the Milky Way stays page-wide, dimmer, so text stays readable. It only draws when the scroll changes (no idle loop), shows a static CSS glow until it is ready or if WebGL is unavailable, and under `prefers-reduced-motion` the sky does not flow. Occasional shooting stars (`NightSky.jsx`) are the only other motion.

`index.html` contains a script that disables the browser console and some devtools shortcuts on the production domain; it is skipped on `localhost` so development is unaffected.

More detail: `docs/portfolio-enhancement/` (audit, design plan, animation/3D strategy, roadmap, acceptance checklist, decisions and the implementation log).
- Hover light: the mouse pointer lights the sky under it. In `AuroraCanvas.jsx` a soft spot (about a fifth of the screen height wide) around the pointer makes the aurora denser and richer in colour and brightens the Milky Way and the stars, and below the hero it gently lifts the dimmed aurora so text stays readable. Kept gentle, and weaker behind the hero text. Hover pointers only (not touch); it eases after the pointer (snaps under reduced motion) and fades out when the pointer leaves the window.
- Text reveal: the home page's section text (hero name and pitch, section labels and headings, project titles and descriptions, tech stack lists, experience and recognition lines, the email and the location) blurs in word by word (letter by letter for the hero name and the email) as it scrolls into view. It is the React Bits `BlurText` component (`src/components/ui/BlurText.jsx`, ported to JSX with the `motion` package) with the site's settings in `src/components/ui/RevealText.jsx`. Links, buttons and tags are not animated, and under `prefers-reduced-motion` the text is plain.
- Preloader: on the first load a night-sky screen with slow aurora curtains, dark hills and a thin progress line covers the page (`src/components/layout/Preloader.jsx`, `.preloader` in `src/index.css`). It waits for the page, the fonts and (on the home page) the first drawn frame of the sky, for at least 1.7 s and at most 4.2 s, then fades away and the hero text blurs in (`src/lib/preloader.js`). It shows once per visit, is CSS only (transform and opacity), and is static under `prefers-reduced-motion`.
- Hero: one justified sentence, "Hi! I'm Jeremiah Pantaras, a software engineer and ..." (`src/components/hero/Hero.jsx`, text in `profile.intro`), with the name in React Bits `ShinyText` (`src/components/ui/ShinyText.jsx`) and the words blurring in after the preloader.
- Opening reveal: on a first visit or a refresh the sky starts empty and, once the preloader has gone, the stars, the Milky Way and the aurora come in over about 4 seconds (`REVEAL_SECONDS` in `AuroraCanvas.jsx`). It plays once per page load.
